# DigitalClockAlarm using Java
A real-time digital clock with alarm functionality built using Java Swing.

## 📌 Project Overview
The Digital Clock with Alarm is a beginner-friendly desktop application developed using Java Swing. It displays the current time in real time and allows users to set an alarm for a specific time. When the scheduled time is reached, the application triggers an audible beep and displays an alert message.

## ✨ Features
- **Real-Time Clock:** Displays the current time and updates every second.
- **Set Alarm:** Allows users to set an alarm using the 24-hour time format (HH:mm).
- **Alarm Notification:** Displays an alert and plays a beep when the alarm time is reached.
- **Stop Alarm:** Allows users to cancel a scheduled alarm.
- **User-Friendly Interface:** Provides a simple graphical interface built with Java Swing.
- **Input Validation:** Checks the alarm time format and displays an error for invalid input.

## 🚀 How to Run the Project

### Prerequisites
- Java Development Kit (JDK) installed
- Visual Studio Code or any Java-compatible IDE

### Steps
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal in the project directory.
4. Compile the Java source file:

   ```bash
   javac DigitalClockAlarm.java
   ```

5. Run the application:

   ```bash
   java DigitalClockAlarm
   ```

## 💻 How to Use
1. Launch the application.
2. View the current time displayed on the screen.
3. Enter the desired alarm time in 24-hour format, such as `18:30`.
4. Click **Set Alarm**.
5. When the scheduled time is reached, the application displays an alert and plays a beep.
6. Click **Stop Alarm** to cancel the scheduled alarm.
